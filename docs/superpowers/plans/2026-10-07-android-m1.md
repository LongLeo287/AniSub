# AniSub Android M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build independently installable Android Vietnamese AI narration with verified model downloads, bounded playback scheduling and tested major-2 Binder interoperability.

**Architecture:** Keep private major-1 system-TTS behavior separate. Java delegates compose an engine-neutral session coordinator, model store, verified catalog, one JNI speech provider and bounded PCM output. AniBox remains untouched; Claude consumes the tested contract when available.

**Tech Stack:** Java 8, Android Java/Views, existing AGP 8.9.1, compileSdk 36/minSdk 23/targetSdk 34; candidate sherpa-onnx JNI; model data outside APK. JUnit 4.13.2 is test-only and must not enter runtime APK. No Compose, Python Android runtime or cloud service.

**Spec:** [Approved System Design](../specs/2026-10-07-anisub-runtime-design.md), approved by user “ok làm đi” after written-spec delivery. [Draft addon contract](../../android-addon-contract.md) supplies current v1 versus proposed v2.

## Global Constraints

- All file paths below are relative to `D:/SEOSONA AI/AniSub`; no AniBox source/settings/secrets edits.
- Preserve Windows/Chrome/Node behavior and installed models. No user-app restart or capture.
- Messenger what=1/payload; JSON <=16,384 UTF-16 units and Bundle <=64 KiB; cues <=16, text <=512, IDs <=80.
- One foreground peer/session; 8 data and 8 control jobs; full control lane disconnects safely.
- One inference worker; two prepared utterances including active; 5-second lookahead; each wave <=30 seconds/8 MiB, combined <=16 MiB.
- 16 pending management requests; ACK deadline 5 seconds; one download plus 2 pending; at most 2 transient retries.
- Store quota 1 GiB by default, optional 4 GiB local setting; incoming expansion reserve plus 128 MiB free space; 64 installed versions.
- One READY model; prepare deadline 60 seconds; unload after 60 seconds without lease -> INSTALLED; OPEN does not implicitly prepare/download.
- Client clock refresh every 1 second while playing; 2-second stale threshold, future tolerance 100 ms; paused state needs no heartbeat.
- Monotonic safe integers <=9,007,199,254,740,991; 256 retired session IDs, 512 recent cue IDs.
- Rate AUTO 0.95–1.15 at phrase boundaries only; unknown end uses natural rate; no exclusive audio-focus GAIN.
- No raw subtitle/image/audio logging; result cache disabled; model code/native libraries are application dependencies, never downloaded model data.
- M1 vi->vi direct text only. No translation/OCR/ASR/dubbing/profile feature implied. Accent/gender unknown unless verified.
- Preserve same-signer signature permission plus exact AniBox UID/package trust. Never copy signing keys or weaken trust to run a test.
- No commit/push/publish/release signing. Workspace currently has no Git; frequent review gates replace plan-template commit steps.
- Execution cannot begin until this written plan is reviewed. Scoped implementer + independent reviewer per AGENTS.md; root integrates and validates.

## Review Focus

1. A caller floods Binder faster than handler consumption: unauthorized senders must not enqueue expensive parsing; bounded trusted ingress must fail closed (Task 6).
2. A file is modified after install verification but before prepare: verify lease assets again before native load, fail MODEL_CORRUPT without speech (Tasks 2/4).
3. Process dies between version-directory rename and registry commit: old usable version survives; startup recovery cannot delete user data (Task 2).
4. Unicode surrogate boundaries, combining marks and long text with no punctuation: preserve text order and reject/split explicitly without lost characters (Task 5).
5. Native synthesis finishes after cancel while audio writer blocks: obsolete PCM never starts; output stop must be bounded independently (Tasks 4/5).
